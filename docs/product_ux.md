# Produto e UX — NarrAIVídeo

## Jornada do usuário (MVP)
1. **Landing** → CTA “Criar vídeo narrado”.
2. **Upload** (foto/vídeo) + consentimentos.
3. **Processando** (status com passos claros).
4. **Editor**:
   - Preview do vídeo/foto
   - Timeline segmentada
   - Editor de roteiro com timestamps
   - Painel de ajustes (voz, pausas, filtros)
5. **Preview de narração** + legendas.
6. **Exportação** com opções (legendas, queima, qualidade).

## Telas principais
- **Dashboard**: lista de projetos, status, data, duração.
- **Upload**: drag‑and‑drop + informações de privacidade.
- **Editor**: timeline + roteiro + ajustes de voz + filtros.
- **Exportação**: formato MP4, resolução, legendas.

## UX de anti‑alucinação
- Painel “Leitura fiel” com três colunas:
  - O que é **certo**
  - O que **parece**
  - **Não dá para confirmar**
- Indicação explícita quando há baixa luz, desfoco ou áudio ausente.

## Consentimento para voz do usuário
- Modal com termos claros e checkbox obrigatório.
- Armazenamento do aceite com timestamp.
